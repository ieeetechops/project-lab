# Katkı Rehberi

Bu depo Project Lab'in kurallarını, şablonlarını ve proje kataloğunu tutar. Proje kodları kendi `lab-*` depolarındadır.

## Nasıl katkı verilir?

| İstiyorsan | Yap |
| --- | --- |
| Yeni proje önermek | [Proje önerisi](https://github.com/ieeetechops/project-lab/issues/new?template=project-proposal.yml) issue'su aç |
| Değerlendirme istemek | [Kapı değerlendirmesi](https://github.com/ieeetechops/project-lab/issues/new?template=gate-review.yml) issue'su aç |
| Bir kuralı değiştirmek | Önce issue'da tartış, sonra PR aç |
| Şablon veya belge düzeltmek | Doğrudan PR aç |

## Değişiklik süreci

1. `main`'den yeni dal aç: `docs/<kısa-açıklama>` veya `governance/<kısa-açıklama>`.
2. Değişikliği yap; Türkçe, kısa ve net yaz.
3. PR şablonunu doldur.
4. Onay kuralları [GOVERNANCE.md](GOVERNANCE.md) içindeki karar tablosuna göredir.

## Etiketler

| Etiket | Anlamı |
| --- | --- |
| `öneri` | Yeni proje önerisi |
| `değerlendirme` | Kapı değerlendirmesi |
| `aşama:değerlendirme` | Kurul incelemesi bekliyor |
| `aşama:kabul` | Kabul edildi; sözleşme bekleniyor |
| `aşama:revizyon` | Revizyon istendi |
| `aşama:ret` | Reddedildi |
| `yönetişim` | Kural değişikliği |
